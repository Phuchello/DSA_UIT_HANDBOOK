PART IX

HEAPS VÀ HÀNG ĐỢI ƯU TIÊN (HEAP & PRIORITY QUEUE)

1. Intuition (Trực giác & Động lực)

Hàng đợi ưu tiên (Priority Queue) là hàng đợi mà phần tử có độ ưu tiên cao nhất luôn được phục vụ trước. Cấu trúc dữ liệu Heap biểu diễn hoàn hảo hàng đợi ưu tiên nhờ khả năng tìm phần tử cực đại/cực tiểu trong $\mathcal{O}(1)$ và cập nhật lại cây trong $\mathcal{O}(\log n)$.

2. Formal Model & Invariants

Max-Heap là Cây nhị phân hoàn chỉnh (Complete Binary Tree) thỏa mãn bất biến: Khóa của nút cha luôn $\ge$ khóa của các nút con.

4. Algorithm & Mechanics (Công thức Chỉ số Mảng)

IT003 CONVENTION: Với mảng bắt đầu từ index 0:

  • $\text{parent}(i) = \lfloor (i - 1) / 2 \rfloor$
  • $\text{left}(i) = 2i + 1$
  • $\text{right}(i) = 2i + 2$

5. C++ Educational & STL Implementation

void heapify(int a[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1, right = 2 * i + 2;
    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;
    if (largest != i) {
        std::swap(a[i], a[largest]);
        heapify(a, n, largest);
    }
}

// C++ STL Priority Queue
#include <queue>
void stlPriorityQueue() {
    std::priority_queue<int> maxHeap; // Max Heap mặc định
    maxHeap.push(50); maxHeap.push(80);
    int topVal = maxHeap.top(); // 80
}

6. Complexity Analysis

Tìm Max: $\Theta(1)$. Chèn / Xóa Max (Heapify): $\Theta(\log n)$. Thuật toán buildHeap tạo Heap từ mảng ngẫu nhiên đạt độ phức tạp tuyến tính $\Theta(n)$.

Giải thích trực giác vì sao buildHeap là $\Theta(n)$: Hầu hết các nút nằm ở đáy cây (mức lá). Lá không cần heapify (chiều cao $h=0$). Chỉ có một vài nút ở đỉnh cây mới cần rớt xuống sâu. Tổng số thao tác rớt của tất cả các nút tạo thành một chuỗi giảm dần hội tụ về $\Theta(n)$. Heap Sort (Build Heap + Extract Max liên tục) đạt $\Theta(n \log n)$.

7. Dry Run Table (Trace Heap Sort)

Thuật toán Heap Sort thực hiện các bước: BuildHeap $\rightarrow$ Extract Max $\rightarrow$ Swap với phần tử cuối $\rightarrow$ Shrink kích thước $\rightarrow$ Heapify root.

Sắp xếp $A = [10, 50, 40]$ (đã là Max-Heap sau buildHeap với kết quả $A=[50, 10, 40]$):

BướcMảng hiện tạiHành độngKích thước Heap
1[50, 10, 40]Đổi chỗ A[0] (50) và A[2] (40)Giảm xuống n=2
2[40, 10, 50]Heapify(A, 2, 0): 40 > 10, giữ nguyênn=2
3[40, 10, 50]Đổi chỗ A[0] (40) và A[1] (10)Giảm xuống n=1
4[10, 40, 50]Hoàn thành, mảng đã sắp xếp tăng dầnn=1
