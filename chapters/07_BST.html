PART VII

CÂY NHỊ PHÂN TÌM KIẾM (BINARY SEARCH TREE - BST)

1. Intuition (Trực giác & Động lực)

Mảng sắp xếp cho phép Tìm kiếm Nhị phân $\mathcal{O}(\log n)$ nhưng chèn/xóa tốn $\mathcal{O}(n)$. Danh sách liên kết cho phép chèn/xóa $\mathcal{O}(1)$ nhưng tìm kiếm tốn $\mathcal{O}(n)$. Binary Search Tree (BST) kết hợp ưu điểm của cả hai: cho phép Tìm kiếm, Chèn, Xóa đều đạt trung bình $\mathcal{O}(\log n)$!

2. Formal Model & Invariants (Định nghĩa & Bất biến)

BST là cây nhị phân thỏa mãn tính chất bất biến tại mọi nút $X$:

  • Mọi khóa ở cây con trái của $X$ đều nhỏ hơn khóa của $X$ ($\text{key}(Left) < \text{key}(X)$).
  • Mọi khóa ở cây con phải của $X$ đều lớn hơn khóa của $X$ ($\text{key}(Right) > \text{key}(X)$).

3. Visual Diagram (Sơ đồ Xóa Nút BST 2 Con)

4. Algorithm & Mechanics (Các thao tác cơ bản)

  • Tìm kiếm (Search): Duyệt từ gốc, nhỏ sang trái, lớn sang phải. $\mathcal{O}(\log n)$.
  • Thêm (Insert): Tương tự tìm kiếm để tìm vị trí nút lá thích hợp rồi chèn.
  • Min/Max: Min nằm ở nút cực trái, Max nằm ở nút cực phải.
  • Duyệt cây (Traversals):
    • Pre-order (NLR): Root $\rightarrow$ Left $\rightarrow$ Right
    • In-order (LNR): Left $\rightarrow$ Root $\rightarrow$ Right (In ra mảng tăng dần)
    • Post-order (LRN): Left $\rightarrow$ Right $\rightarrow$ Root
  • Xóa (Delete) - 3 Trường hợp:
    • Nút lá: Xóa trực tiếp nút.
    • Nút có 1 con: Nối cha của nút cần xóa trực tiếp tới nút con của nó.
    • Nút có 2 con: IT003 CONVENTION Thay bằng Nút cực phải của cây con trái (Max Left) hoặc Nút cực trái của cây con phải (Min Right).

5. C++ Educational Implementation

// Search (Recursive)
TreeNode* search(TreeNode* root, int key) {
    if (!root || root->data == key) return root;
    if (key < root->data) return search(root->pLeft, key);
    return search(root->pRight, key);
}

// Search (Iterative)
TreeNode* searchIterative(TreeNode* root, int key) {
    while (root != nullptr && root->data != key) {
        if (key < root->data) root = root->pLeft;
        else root = root->pRight;
    }
    return root;
}

// LNR Traversal
void inOrder(TreeNode* root) {
    if (root) {
        inOrder(root->pLeft);
        std::cout << root->data << " ";
        inOrder(root->pRight);
    }
}

TreeNode* findMin(TreeNode* root) {
    while (root && root->pLeft != nullptr) root = root->pLeft;
    return root;
}

TreeNode* findMax(TreeNode* root) {
    while (root && root->pRight != nullptr) root = root->pRight;
    return root;
}

TreeNode* deleteNode(TreeNode* root, int key) {
    if (root == nullptr) return root;

    if (key < root->data) root->pLeft = deleteNode(root->pLeft, key);
    else if (key > root->data) root->pRight = deleteNode(root->pRight, key);
    else {
        if (root->pLeft == nullptr) {
            TreeNode* temp = root->pRight;
            delete root; return temp;
        } else if (root->pRight == nullptr) {
            TreeNode* temp = root->pLeft;
            delete root; return temp;
        }
        TreeNode* temp = findMin(root->pRight); // Min Right
        root->data = temp->data;
        root->pRight = deleteNode(root->pRight, temp->data);
    }
    return root;
}

6. Complexity Analysis

Các thao tác Tìm kiếm, Chèn, Xóa trên BST có độ phức tạp phụ thuộc trực tiếp vào chiều cao của cây: $\mathcal{O}(h)$.

  • Cây cân bằng tương đối ($h = \Theta(\log n)$): Các thao tác đạt hiệu năng lý tưởng $\mathcal{O}(\log n)$.
  • Cây suy biến tệ nhất (Skewed Tree, $h = n$): Cây bị suy biến thành Danh sách liên kết, các thao tác tốn $\mathcal{O}(n)$.
